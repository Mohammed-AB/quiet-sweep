# Quiet Sweep design system

Direction: minimal Swiss-inspired dashboard. UI/UX Pro Max search `privacy cleanup dashboard minimal` returned Minimalism & Swiss Style; this fits a privacy utility. The generic marketing-page structure was not applied to the task workspace. Plain HTML/CSS/ES modules detected; no framework guidance was substituted.

## Adapted palette
Dark navy navigation (#152c3b), ivory-gray canvas (#f6f7f9), white cards, strong ink (#172b39), readable muted text (#586b79), pale lime supporting accent (#d9ef9f), dark green accent text. One light content theme; the navy navigation is not a separate dark mode.

## Hierarchy and layout
48–60px hero, 16px card headings, 14–16px primary controls, 12–14px supporting content. Small metadata may use 10–12px; never use low-contrast fine print for essential instructions. System sans-serif, Georgia for restrained editorial accent, system mono for metadata. No third-party font requests.

24px card gutters, 16px radii, consistent 8px control corners. Three-step workflow above two working panels. Full preview message list, not a five-message sample. Bottom navigation below 768px retains text labels and safe-area clearance.

## Interaction
At least 44px primary pointer targets. Keyboard skip link, current navigation state, visible focus ring, real native controls, labeled progressbar, dialog title, inline range error and focus after failed submit. Consistent custom outline SVG icons hidden from assistive technology when adjacent text labels them. Reduced-motion removes animation and transitions.

## Search-backed guidance
`error summary validation --domain ux` returned Focusable Error Summary and Error Messages. A one-error date form uses an announced, focusable inline range error; both date fields reference it. No toast-only failure.

Preserve synthetic-only demo behavior, scope protections, credit ledger and purchase paths. Browser-check desktop/mobile and cleanup/checkout after changes.
